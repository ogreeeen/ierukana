# いえるかな？（Android版）

2歳向けの「ことばを言えたらスマホじかん」アプリ。

- 絵を見て名前を言う → 正解5点／近い言葉3点／何か声が出たら1点
- ⭐5つで3分間スマホを自由に使える（自動でホーム画面へ）
- 3分たつと、どのアプリを使っていても全画面の「おしまい！」が出て、クイズに強制的に戻る
- ごほうび時間以外は、ホームボタンなどでクイズから抜けても引き戻される
- おうちのひとが終わるとき：クイズ画面右下の 🚪 →「おわる」を3秒長押し
  （「おしまい！」画面では右下の「おうちのひと」を長押しで解除）

## APK の作り方

### A. GitHub で自動ビルド（PC不要）
1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてアップロード
2. 「Actions」タブでビルドが自動で走る（5分ほど）
3. 「Releases」の「いえるかな？ 最新版」から `ierukana.apk` をスマホでダウンロード

### B. Android Studio でビルド
1. Android Studio でこのフォルダを開く
2. メニュー Build → Build APK(s)
3. `app/build/outputs/apk/debug/app-debug.apk` をスマホへ

## 初回セットアップ（スマホ側）
1. APK を開いてインストール（「提供元不明のアプリ」を許可）
2. 起動してマイク・通知を許可
3. 「他のアプリの上に重ねて表示」を許可（アプリ内の案内に従う）
4. 設定 → アプリ → いえるかな？ → バッテリー →「制限なし」にすると、タイマーが止められにくくなる

## カスタマイズ
`app/src/main/assets/index.html` の先頭付近
- `GOAL`：ごほうびまでの点数（初期値 5）
- `REWARD_SEC`：ごほうび時間の秒数（初期値 180）
- `WORDS`：出題することば（絵文字・正解・近い言葉）
